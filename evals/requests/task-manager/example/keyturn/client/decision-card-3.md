# Decision: How should the screens look?

- Status: answered
- Related: R-10, AC-10 to AC-13

## Summary

We need to know how far the look of the screens is worked out, and whether a ready-made set of screen parts (a UI library) is used. We recommend a tidy minimum without a UI library. You can also leave it to us: we then take our recommendation. If you do not answer, nothing is designed until you do.

## Context

You will judge the app by its screens, so the requirements say how they should look. Whatever you choose, every page is tidy (R-10): labels sit with their fields, buttons line up, the pages fit a phone, and you can see where you are with the keyboard (AC-10 to AC-13). Your request does not mention the look, so we ask once, now.

## Options

1. **A tidy minimum, without a UI library (recommended)**: plain, neat pages that meet AC-10 to AC-13 and nothing more. Nothing is added to the app for the look.
2. **Worked out further, with a UI library we choose**: the same colors, type sizes, and spacing on every page, and more polished buttons and fields, from a widely used UI library. We add criteria for it to the requirements, and you agree to the library with the design. Takes longer to build and check.
3. **Worked out further, with a UI library you name**: as option 2, with the library you choose. We check it like anything else the app uses, and tell you if it does not pass.

If you would rather not choose, say "leave it to you": we take option 1.

## Our recommendation

Option 1: the app is a to-do list for you and a few friends, so neat, plain pages serve it well, and nothing extra has to be built, checked, or kept up to date (R-10).

## If you do not answer

Nothing is designed until you answer: the requirements are not approved without it. We never choose for you, not even our recommendation.
